# Database Design

## Entities

### Project
Проект объединяет задачи вокруг долгосрочной цели пользователя.

### Task
Задача описывает конкретное действие. Может принадлежать проекту или существовать отдельно.

### Subtask
Подэтап принадлежит задаче и помогает разбить её на части.

### Notification
Внутреннее уведомление показывает важные события внутри приложения.
