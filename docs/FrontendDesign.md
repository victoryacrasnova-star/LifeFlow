# Frontend Design Brief

## Общий стиль

LifeFlow должен выглядеть как спокойный планировщик без перегруженного интерфейса.

Ключевые ощущения:

- чисто;
- понятно;
- спокойно;
- без визуального шума;
- пользователь сразу понимает следующий шаг.

## Главные экраны

### 1. Первый запуск

Пользователь видит приветствие и предложение создать первый проект.

Основной CTA:

- Создать проект

### 2. Мой день

Главный рабочий экран.

Показывает задачи текущего дня, сгруппированные по категориям:

- Учёба
- Работа
- Личное
- Другое

### 3. Проекты

Экран со списком проектов.

Каждый проект показывает:

- название;
- категорию;
- количество активных задач.

### 4. Экран проекта

Показывает задачи внутри проекта.

### 5. Экран задачи

Показывает:

- название;
- описание;
- дедлайн;
- подэтапы;
- статус.

## UX-принцип

LifeFlow не должен оставлять пользователя в тупике.

Если экран пустой, приложение предлагает следующий шаг:

- создать проект;
- добавить задачу;
- посмотреть задачи на завтра.

## Адаптивность

Интерфейс проектируется по принципу responsive web design.

Минимальные целевые форматы:

- desktop;
- mobile browser.

В мобильной версии боковое меню может открываться свайпом или через кнопку меню.
