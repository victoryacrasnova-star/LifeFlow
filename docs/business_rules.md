## BR-001. Объединение просроченной задачи

### Описание

Пользователь решил объединить просроченную задачу с задачей текущего дня.

### Условие

Пользователь выбрал действие "Объединить".

### Поведение системы

- объединить невыполненные подэтапы;
- сохранить выполненные;
- убрать дубликаты.

### Результат

Создаётся одна актуальная задача без повторяющихся подэтапов.

BR-002

Поведение выполненных подэтапов

BR-003

Обработка одинаковых подэтапов
